# Security policy

## Report a vulnerability privately

Do not open a public issue for a suspected vulnerability.

Use GitHub's
[private vulnerability reporting form](https://github.com/N9-Developer-Empowerment/sunofriend/security/advisories/new).
Include the affected version or commit, the smallest safe reproduction,
expected impact and any suggested mitigation. Do not include stems, private
music, credentials, tokens or another person's personal information.

If GitHub's private reporting form is unavailable, email
[hello@sunofriend.com](mailto:hello@sunofriend.com) with the subject
`[SECURITY] Request for a private reporting channel`. Do not put exploit
details in that first email.

Sunofriend is currently an alpha. Supported security fixes target the latest
public `main` revision unless a published advisory says otherwise.
